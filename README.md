# Agenda
Este proyecto es una aplicación simple en Python para gestionar una agenda de eventos.  
Los eventos se almacenan en un archivo CSV.

## Requisitos

Antes de ejecutar el programa necesitas:

- Python 3 instalado
- La librería estándar `csv` (ya viene incluida en Python)# agenda
## Instalación de pandas

Este proyecto utiliza la librería **pandas** para manejar los datos del archivo CSV.

Para instalarla ejecuta:

pip install pandas
